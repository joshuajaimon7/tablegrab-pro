# TableGrab Pro 📊

> **Instant HTML Table & Repeating List Extractor for Google Chrome.**  
> Extract tables from any website to clean CSV, TSV (Excel/Sheets), or JSON in 1 click. 100% private and runs entirely in your browser.

🌐 **Live Website:** [https://joshuajaimon7.github.io/tablegrab-pro/](https://joshuajaimon7.github.io/tablegrab-pro/)  
🔒 **Privacy Policy:** [https://joshuajaimon7.github.io/tablegrab-pro/privacy.html](https://joshuajaimon7.github.io/tablegrab-pro/privacy.html)

---

## ✨ Features
- **In-Page Hover Inspector:** Move cursor over any table to view instant row/col dimensions and a quick 1-click export badge.
- **Clean RFC 4180 CSV Export:** Properly handles nested quotes, commas, and linebreaks without breaking spreadsheet columns.
- **Sheet-Ready Clipboard Copy:** Copies tab-separated values (TSV) directly to clipboard so you can press `⌘ + V` right into Google Sheets or Microsoft Excel.
- **JSON Data Export:** Converts rows into clean structured JSON objects using table headers.
- **Multi-Table Detection:** Scans full pages and lets you switch between multiple tables with live previews.
- **100% Private & Client-Side:** No cloud servers, no data collection, no telemetry.

## 🛠️ Local Installation (Developer Mode)

1. Clone or download this repository:
   ```bash
   git clone https://github.com/joshuajaimon7/tablegrab-pro.git
   ```
2. Open **Google Chrome** and navigate to `chrome://extensions/`.
3. Enable **Developer mode** (toggle in the top-right corner).
4. Click **Load unpacked** (top-left) and select the `tablegrab-pro` folder.
5. Open any webpage with tables (or open `demo-test.html`), hover over a table, or click the TableGrab icon in your toolbar!
